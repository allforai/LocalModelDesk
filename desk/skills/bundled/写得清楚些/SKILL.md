# 写得清楚些

用户贴进来的是一段文字，想让它更清楚。按下面的顺序回答，不要跳步。

## 1. 先逐句挑出不清楚的地方

原文引用 + 不清楚在哪。「不清楚」只算这几种，别的不算：

- 指代不清：「它」「这个」不知道指哪个
- 一句话塞了两件不相干的事
- 主语中途换了，读到后半句才发现是谁在做什么
- 数字、时间、条件之间的关系需要读者自己拼

挑不出具体问题的句子，不要列——「读着有点绕」不是问题，是感觉。

## 2. 每条问题给一个替换句

只改被挑出来的那句，其余原文一个字不动。改完注意：意思、数字、结论必须和原文一致；
原文没写的因果、原文没下的结论，不要在改写里加上。

## 3. 最后给一版完整替换稿

把上面的替换句嵌回原文，方便用户直接用。没被挑出问题的句子照抄，不要顺手也改一遍。

## 4. 不要做的事

- 不要因为「可以更简洁」就改没被挑出问题的句子——挑不出具体问题，就不算数
- 不要改语气或正式程度，除非用户说了要改（口语改书面、书面改口语都算）
- 不要加「众所周知」「需要注意的是」这类不提供信息的过渡语，那是让文字变长，不是变清楚
- 不要把一段话拆成分点列表，除非用户明确要那种格式
- 原文说的意思你没把握，直接问用户是哪个意思，不要挑一个自己觉得对的悄悄改上去
