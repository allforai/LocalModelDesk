# observed-style（盘问官综合，非基线）

来源：docs/visual/*.candidate.json（从代码读出、带 basis 的候选规则）、desk/static/app.css、
evidence/visual-style/ 实测官独立截图（Chromium 151 有头、DPR 1；1440x900 / 900x600 / 1920x1080）与读回、
evidence/q01-J5/ 旅程截图。截图中的缺陷不是基准。

## 实图与候选规则一致的部分（供逐类确认参考）
- 只有深色主题：所有截图深色；prefers-color-scheme 读回 false 时仍渲染深色（color-scheme: dark 写死）。
- 强调色蓝用于活动标签下划线、新会话主按钮、选中会话卡片描边；状态条下沿一条线随状态变色（空闲绿 / 忙橙）。
- 资源页每行「删除」为实心危险色按钮（vs-05）；会话卡片面板底 + 描边 + 圆角，选中改描边为强调色。
- 字号：正文 14px 一种，次要信息 13px 灰；根字号读回 16px，全站 px，不随根字号缩放。
- 状态条窄档（≤1100px）短标签：「视频生成中 · 媒体：忙 · 忙」（vs-15）。
- 素材库网格列数 6@1440 / 4@900 / 8@1920；聊天主列 1080@1440、1400@1920（max 1400）。

## 实图里出现、规则尚未表态的部分（逐类确认时需用户定）
- 文档级滚动：聊天/图片/视频/音乐整页不滚、区内滚；资源/素材库整页滚，8px 常显滚动条使右上「设置」按钮横移约 8px（vs-01 vs vs-05）。
- 视频/音乐/图片页：结果区（时间线）与下方表单上下相邻，窗口矮时结果区被压到 159px（视频 900x600，vs-15）、134px（音乐）；单张卡片高于结果区时被上缘或下方表单截断（q01-J5 第 7、8 步）。
- 宽窗（1440/1920）下视频/音乐页单张卡片与下方表单之间大段空白（vs-21：卡片止于 y≈375，表单起于 y≈840）。
- 竖屏视频在横向宽播放框中两侧黑边（q01-J5 第 8 步）。
- 设置抽屉打开时 body overflow 变 hidden，抽屉自身滚动（913/900）。
