# 模块 spec：e2e

**单一职责** UI 级别的自动化验收。用真实浏览器驱动真实台面服务，把 README 的用户旅程逐条证明。

## 来源

人类在 Phase 1 中途要求「增加一遍 ui 级别的自动化测试验收任务」（决策 D-0001）。
本模块因此新增，`ui` 模块保持原样（`ui` 已估 14 任务，合并会突破 20 任务拆分线）。

## 技术选型（已冻结，D-0001）

- **Python Playwright + pytest**，不是 npm Playwright，也不是 MCP 工具调用。
  - `acceptance_cmd` 必须是 supervisor 能独立重跑的 shell 命令；MCP 工具调用不是。
  - 零 `node_modules`，不违反 Phase 0 冻结的「原生 ES 模块、无构建链」。
  - 实测：`playwright` 1.62.0 arm64 wheel 可下载；`~/Library/Caches/ms-playwright` 已缓存
    `chromium-1223` 与 `chromium_headless_shell-1223`，无需下载浏览器。
- 测试文件位于 `tests/e2e/`，验收命令形如 `python3 -m pytest tests/e2e/test_<flow>.py`。

## 测试态服务（本模块的核心资产）

e2e **绝不加载真实模型、绝不跑真实推理、绝不触碰 339G 真权重**。
本模块提供 `api:launchTestHarness`：以下述注入启动一整套真实的台面服务——

| 注入点 | 假实现行为 |
|---|---|
| LLM 后端 | 立即「就绪」；`chat_stream` 吐出可预测的正文增量与 `reasoning` 增量 |
| 媒体执行器 | 按脚本产出进度行，并在 outputs 根写入一个极小的真 `.mp4` / `.wav` |
| 下载执行器 | 按脚本推进字节数，可被取消，可续传 |
| HF 清单 | 固定的假清单，配合预置的 齐 / 一半 / 没下 三种目录树 |
| 数据根 / 模型根 | 全部指向 `tmp_path` |

除以上注入点外，**服务、路由、前端、状态机全部是真的**——这正是它比单元测试多证明的部分。

## 需求

- **R-e2e-01** 测试态服务可启动：注入假后端、临时数据根与临时模型根，浏览器可访问，
  全流程确定性可重复；断言全程未触碰真实权重目录与真实 outputs。
- **R-e2e-02** 首运流程：无配置时呈现首运界面；选定 models 目录后进入主界面；配置确已落盘。
- **R-e2e-03** 聊天流程：选模型 → 加载 → 发消息 → 看到**逐步增长**的流式正文 → 思考块可展开 → 回复入库。
  必须断言「增量确实是分批到达的」，而不是一次性出现（否则流式没被证明）。
- **R-e2e-04** 多会话：新建 / 切换 / 重命名 / 删除；**刷新页面后仍在**。
- **R-e2e-05** 资源面板：齐 / 一半 N% / 没下 三态正确渲染且百分比正确；
  下载 → 进度推进 → 取消 → 续传 的控件流转；删除需二次确认；剩余空间可见。
- **R-e2e-06** 视频流程：填参数 → 启动 → 进度可见 → 完成后播放器出现且 `src` 指向新成品。
- **R-e2e-07** 音乐流程：同上。
- **R-e2e-08** 互斥在 UI 上可见：媒体运行中，加载按钮与另一媒体按钮均被禁用，状态条给出拒绝原因；
  媒体结束后恢复可用。
- **R-e2e-09** 素材库：点历史项把当时参数回填进对应表单（逐字段断言）；点成品可播放。
- **R-e2e-10** 状态条显示**真实内存数值**并随状态变化；断言页面上不存在写死的 `128` 内存字面量。
- **R-e2e-11** 设置面板显示对外 API 的两条 base URL（OpenAI 与 Anthropic），并明示当前无鉴权。
- **R-e2e-12** **零直连断言**：通过浏览器网络拦截，断言整场 e2e 期间前端**没有向 `127.0.0.1:8767`
  发出任何请求**。这条以行为方式证明 census A17，比 grep 更强。

## 验收取向

每条需求一个 pytest 文件，`python3 -m pytest tests/e2e/test_<flow>.py`，headless chromium。
**全部为自动验收，无 reality gate**——这正是本模块存在的理由。

反同义反复要求：每个测试必须断言具体的 DOM 文本 / 属性 / 网络行为，
不得只断言「页面加载成功」或「元素存在」。R-e2e-03 必须断言增量分批到达；
R-e2e-12 必须断言请求计数为零而非仅检查页面源码。
