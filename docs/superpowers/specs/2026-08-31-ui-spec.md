# 模块 spec：ui

**单一职责** 静态前端。五个面板 + 一条常驻状态条。

## 背景约束

现状整个前端是 `server.py` 里的一个 `HTML = r"""..."""` 字符串。
拆成真实静态文件：`index.html` + `app.css` + 若干 ES 模块，由服务端静态供给。
**无构建链、仓库零 `node_modules`**（人类明示）。

前端只与台面 HTTP 接口对话，**不得再直连 `127.0.0.1:8767`**。

## 需求

- **R-ui-01** 前端是静态文件（`index.html`、`app.css`、ES 模块），由服务端供给；
  Python 源码里不再存在内联 HTML/CSS/JS 字符串。
- **R-ui-02** 聊天面板：模型选择、加载/卸载、流式回复、思考过程可展开、左侧会话列表（新建/切换/重命名/删除）。
- **R-ui-03** 视频面板：提示词、画幅、帧数、步数、进度、完成后就地播放。
- **R-ui-04** 音乐面板：风格描述、歌词、时长、进度、完成后就地播放。
- **R-ui-05** 资源面板：每个模型显示 `齐` / `一半 N%` / `没下`、体积、实际占盘，
  以及 下载 / 续传 / 取消 / 删除 控件；`partial` 要能看到缺哪些文件；显示卷剩余空间。
- **R-ui-06** 素材库面板：成品与历史，点击播放，点击把当时的参数回填进对应表单。
- **R-ui-07** 常驻状态条：真实内存（不是写死的 128）、内存里是谁、媒体是否在跑、现在能不能开下一件重活。
- **R-ui-08** 加载装不下的模型前弹出内存警告，确认后才继续。
- **R-ui-09** 首运界面：选择 models 目录，或收编一个既有目录树。
- **R-ui-10** 设置界面：对外 API 的开关、主机、端口，并显示可复制的 base URL
  （OpenAI 与 Anthropic 各一条），旁边注明当前是无鉴权监听。

## 验收取向

- 服务端侧：断言每个静态资源可取到且 `Content-Type` 正确；断言 Python 源码中不存在内联 HTML 字符串
  （对 `desk/` 下所有 `.py` 做检查，找不到 `<!doctype` / `<html`）。
- 前端逻辑：把纯函数（状态渲染、百分比格式化、参数回填映射）拆成可在 Node 下直接跑的 ES 模块并做单元测试
  （`node --test`，无依赖）。
- DOM 交互与视觉：标 `reality_gate`，附人工验证 runbook（逐面板点一遍）。
