## 0. 范围与非目标

**范围**
- 视频页改成会话式，建在共用控制器 `panes/media_session.js` 上（第三个使用方）。
- 三个动作：在这段基础上改 / 换个版本 / 接着往下生；成片播放、重新拼接、挑选合成（与音乐相同的机制）。
- 从图片会话挑图作首帧：视频页「从图片会话选…」、图片页「用这张生成视频」。
- 后端：视频 `session_id` 必填；注册 `refs` 槽 `video.first_frame → image` 并接入 H3 命令。
- 控制器清理：`attemptView` 通用化；控制器接口去掉图片专属命名。

**非目标**
- [V-00a] 配乐（D1、D2）归 3b。
- [V-00b] 尾帧不支持从图片会话选（只支持上传）；参考视频不支持从视频会话选。
- [V-00c] 不改 H3 命令行、预算、耗时估算公式。
- 台面未发布，不谈兼容。

## 1. 后端

- [V-01] `start_video_job` 的 `session_id` 必填（同 M-50 文案与状态码）。
- [V-02] `MediaService` 默认注册引用槽 `{"video": {"first_frame": "image"}}`（构造参数 `ref_slots` 未传时使用该默认；测试可覆盖）。
- [V-03] 请求带 `refs.first_frame`：要求 `mode == "image"`，且请求不再带 `first_frame` 素材 id；否则 400 `invalid_params`「首帧只能从上传或图片会话二选一」。`continues` 与 `refs.first_frame` 同时出现 → 400（沿用 CONTINUE_CONFLICT 文案）。
- [V-04] 解析出的图片路径直接作为 H3 `--first-frame` 参数；`params.first_frame` 记为 `null`（尝试的 `refs` 已记下引用，B-56）。引用失效 → 404 `ref_missing`「引用的图片已不在」（B-55）。
- [V-05] 历史条目与素材库不变；`fillPlan` 对 video 条目带出 `refs`（`entry.params` 不含 refs，故 history 条目增加顶层 `refs` 字段，只在非空时出现）。

## 2. 控制器清理

- [V-10] `attemptView(attempt, {broken, noun})` 移到 `pure/media_session.js`：missing 文案「<noun>文件已不在」（图片页仍得到「图片文件已不在」，逐字不变）；音乐卡片改用它（传 `noun: "音频"`，文案「音频文件已不在」——音乐卡片当前的「文件已不在」改为此）。
- [V-11] 控制器 `renderCard` 返回的 `recompose` 改名 `secondary`（`{button, hint}`），`composer.updateAvailability(state, {secondary})`；卡片参数 `noImageReason` 改名 `secondaryBlockedReason`。图片页行为与文案不变（M-04 规则同样适用：`tests/js/image_pane.test.js` 断言不改）。

## 3. 视频页

### 3.1 布局（`#pane-video`，与图片/音乐同构）

- [V-20] 左栏会话、头部「生成视频」+ 模型状态 + 「模型说明」（MiniMax H3 · MLX 本机推理；输出带声音的 MP4；「接着往下生」用上一段的最后一帧作首帧，拼接处可能有动作跳变）、时间线、底部输入区。原表单 + jobview 删除。
- [V-21] 输入区（自上而下）：提示条（V-30）；「生成方式」`<select>`（文生视频 / 图生视频 / 视频参考生成）；素材行（按方式出现，V-22）；提示词 `<textarea>`（默认 3 行，聚焦/超出时增高，最高 40vh；placeholder 随方式变化，沿用现有三条）与「生成视频」主按钮（⌘Enter）；「AI 帮写」行；「高级参数」`<details>` 默认折叠：画幅（现有三档）、视频时长（现有六档）、耗时提示（`videoCostNote`）、步数（默认 16，4–50）、种子（留空则每次随机）、「使用素材的声音」勾选（仅图生/参考方式可见，默认勾选）；上传状态行；状态行；错误行。
- [V-22] 素材行：
  - 图生：首帧区（「上传图片」按钮 + 「从图片会话选…」按钮 + 预览 + 来源说明）、尾帧区（「上传图片（可选）」+ 预览 + 「清除尾帧」）。拖放上传沿用现有行为（issue #15）。
  - 参考：参考视频区（上传 + 预览）。
  - 首帧来源说明三种：「已选择：<文件名>」「首帧：图片会话「<标题>」第 N 次」「接在第 N 次后面（用它的最后一帧）」（续写时，首帧区按钮禁用）。
- [V-23] 「从图片会话选…」打开选择框（`confirmDialog` 风格的模态，`role="dialog"`，标题「从图片会话选首帧」）：左侧图片会话列表（标题 + N 次生成），右侧该会话中 `done` 且文件在的图片缩略图网格；点缩略图即选中并关闭；「取消」关闭不改变。无可选图片时显示「这个会话还没有生成好的图片」。
- [V-24] 空会话：「还没有视频」／「在下面写提示词，点「生成视频」。之后可以在任意一段上「在这段基础上改」「换个版本」或「接着往下生」。」
- [V-25] 「种子」只出现在高级参数内。

### 3.2 卡片

- [V-30] 提示条三种（互斥）：沿用「沿用第 N 次」（规则同 M-26 沿用型）；续写「接在第 N 次后面」（同 M-26 续写型，续写目标失效同 M-28，文案「第 N 次的文件已不在，不能接着往下生」）；素材库「沿用素材库里这段」。
- [V-31] 折叠：「第 N 次 · HH:MM」＋「接第 M 次」／「合成：第 a、b 次」；方式标签（文生 / 图生 / 参考）；提示词摘要（两行省略）；规格「512×288 · 约 3 秒 · 16 步」（时长文案取 DURATIONS 最接近项）；状态标记。
- [V-32] 展开 done：`<video controls preload="metadata">`（宽不超过时间线列宽，高不超过 50vh），有可用成片时默认播成片，「成片 | 只看这一段」切换（同 M-31）；续写链说明「由：第 1 次 → 第 3 次」；成片问题行与「重新拼接」（同 M-40–M-42）；首帧来源行（图生且有 refs.first_frame：「首帧：图片会话「<标题>」第 N 次」；标题取不到时「首帧：来自图片会话」）；完整提示词；「高级参数」折叠（画幅、时长、步数、种子）；动作按钮。
- [V-33] 失败 / 取消 / 文件不在：同图片卡片规则（图标块，无 `<video>`）。`<video>` 报错 → 文件不在状态。
- [V-34] 挑选合成模式：同 M-06/M-07 与最终修订（卡片只做勾选，不显示动作与「重新拼接」）。

### 3.3 动作

- [V-40] **在这段基础上改**：回填方式、提示词、画幅、时长、步数、种子；图生时回填首帧来源（上传素材 id 作为已保存素材 / 图片会话引用 / 续写关系）与尾帧；参考时回填参考视频素材 id；提示条「沿用第 N 次」；不提交。若首帧来源为图片会话引用且已失效 → 首帧区显示「引用的图片已不在」并清空首帧来源。续写段回填后生成仍接在原位置（带原 `continues`）。
- [V-41] **换个版本**：立即提交原尝试参数（含素材 id / 引用 / `continues`），种子换新随机数≠原值。
- [V-42] **接着往下生**：方式切到图生、首帧来源为续写（V-22 第三种说明）、尾帧清空；提示词清空；画幅、时长、步数沿用该段；种子清空；提示条「接在第 N 次后面」；焦点到提示词。仅 done 且文件在可用，否则原因「这一段没有生成好，不能接着往下生」。compose 尝试：画幅、时长、步数保留输入区当前值。
- [V-43] 生成成功启动后：提示词、方式、画幅、时长、步数保留；种子清空；沿用/续写提示条隐藏；续写的首帧来源清空（回到「未选择」）；上传与图片会话来源保留。

### 3.4 图片页「用这张生成视频」

- [V-50] 图片卡片展开时，done 且图片在的卡片在两个动作右侧增加次级按钮「用这张生成视频」。点击：切到视频页，方式设为图生，首帧来源设为该图片的引用（`{kind:"image", session_id, attempt_id}`），首帧说明「首帧：图片会话「<标题>」第 N 次」，提示词不变，焦点到提示词。图片页其余行为不变（新增按钮不影响现有按钮与文案）。
- [V-51] 跨页通信经 `main.js`：图片页 `ctx.onUseAsFirstFrame(ref, label)` → `showTab("video")` → `panes.video.useFirstFrame(ref, label)`。

### 3.5 接通

- [V-60] `main.js`：`tickJob` 对 `kind == "video"` 调 `panes.video.applyJob`；`showTab("video")` 调 `panes.video.refresh()`；`applyFill` 对 video 与 image/music 同样走 `panes.video.applyFill`；模型状态 `h3` 目录项、运行环境 `mlx_h3` 能力；删除所有 `jobView` 使用；`widgets/jobview.js` 若不再被任何页面使用则删除（其纯函数部分已在 `pure/`）。
- [V-61] 素材库回填视频条目：同 M-52（找得到会话 → 打开并执行「在这段基础上改」；否则按字段回填、提示条「沿用素材库里这段」）。

## 4. 测试与完成标准

- 后端：视频缺会话 → 400；`refs.first_frame` 解析为 `--first-frame <路径>`、与上传首帧冲突 400、与 `continues` 冲突 400、失效 404 `ref_missing`；history 条目带 `refs`。
- 纯逻辑：`pure/video_session.js`（`readVideoParams`、三个动作请求、提示条、卡片文案、规格行）；`attemptView` 通用化（图片文案不变、音频文案）。
- 控制器改名后：`tests/js/image_pane.test.js` 断言不改，全过。
- 视频页单测：方式切换与素材行显隐；上传素材复用；从图片会话选首帧（选择框列出会话与缩略图、选中后说明文案、提交带 `refs.first_frame` 不带 `first_frame`）；三个动作；续写首帧说明与首帧区禁用；主流程无「种子」。
- 图片页：「用这张生成视频」按钮存在且回调参数正确（新增断言，不改旧断言）。
- e2e `tests/e2e/test_video_sessions.py`：生成（文生）→ 接着往下生 → 成片切换出现 → 在图片页「用这张生成视频」→ 视频页首帧说明正确 → 生成 → 会话文件 `refs.first_frame` 正确；挑两段合成；900×700 无横向滚动。现有操作旧视频页的 e2e（`grep -rln "data-video-" tests/e2e`）迁到新页面并保持意图。
- 全量：`python3 -m pytest -q --ignore=tests/e2e`、`node --test tests/js/`、`python3 -m pytest tests/e2e -q`。

**完成标准**：图片零回归；视频 e2e 走通；`main.js` 与 `desk/static` 中不再引用 `jobView`；视频不带会话被拒。
