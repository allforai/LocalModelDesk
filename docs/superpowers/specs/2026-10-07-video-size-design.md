## 1. 尺寸规则（pure/video_size.js 与 desk/media/service.py 同一套）

- [Z-01] 合法画幅：宽、高都是整数且为 32 的倍数；每边 256–1344；`宽×高 ≤ 768×1344`。
- [Z-02] 违规文案（按此顺序取第一条）：「宽和高须为整数」「宽和高须为 32 的倍数」「每边须在 256–1344 之间」「面积不能超过 768×1344（约 103 万像素）」。
- [Z-03] 后端 `start_video_job` 在任何会话写入之前做同样校验，违规返回 400 `invalid_params`，文案「画幅须为 32 的倍数，每边 256–1344，面积不超过 768×1344」；拒绝时会话不留尝试记录（B-33）。
- [Z-04] 镜像测试：一个 Python 测试读出 JS 与 Python 两边的常量（32、256、1344、768×1344）和内存公式参数（27.0、1.4、草稿体积 512×288×49、预算 40），任何一边改了另一边不跟就失败。

## 2. 方向与档位

- [Z-10] 方向：`landscape` 横屏 / `portrait` 竖屏 / `square` 方形。
- [Z-11] 档位（名称 草稿 / 标准 / 清晰）：横屏 512×288、768×448、1024×576；竖屏为横屏宽高对调；方形 384×384、576×576、768×768。全部满足 Z-01。
- [Z-12] 方向控件在输入区主行，是分段控件（复用 `widgets/segment_switch.js`，`ariaLabel`「画幅方向」）；档位下拉在「高级参数」的「画幅」处，选项随方向变，末项「自定义…」。
- [Z-13] 切换方向时保持同一档（草稿→草稿……）；当前是自定义时切方向，取新方向的「标准」档。
- [Z-14] 选「自定义…」出现宽、高两个数字输入，初值为切换前选中的那一档；输入框失焦时取最近的 32 的倍数（`snap32`）；提交前不合规按 Z-02 写在高级参数错误行并拦下（沿用现有 `ParamsError({advanced:true})`）。
- [Z-15] 默认：横屏 · 草稿（与现状 512×288 一致）。

## 3. 首帧自动跟随（用户选 A）

- [Z-20] 形状判定：`0.9 ≤ 宽/高 ≤ 1.1` 为方形；否则宽>高为横屏、高>宽为竖屏。
- [Z-21] 「图生」模式下首帧来源变化（上传选中、从图片会话挑选、回填带入的图片会话首帧）且读到首帧尺寸后：若当前不是自定义且首帧方向 ≠ 当前方向，就切到首帧方向、保持档位（Z-13），在首帧说明旁提示「已按首帧切到<方向>」。
- [Z-22] 首帧尺寸来源：上传文件在浏览器里解码读 `naturalWidth/Height`；图片会话引用读该尝试的 `params.width/height`（`panes/video.js` 的 `lookupImage` 现只返回 `{output,title,index}`，需补上 `width,height`）；读不到（解码失败、参数缺失）就不跟随、不提示。
- [Z-23] 跟随后用户手动改方向：照用户的，提示消失，同一个首帧不再自动切回。换了新的首帧重新判定。
- [Z-24] 当前是自定义尺寸时不自动改，形状不一致时提示「首帧是<方向>，画幅是<方向>，画面会被裁切或拉伸」。
- [Z-25] 续写的首帧（上一段末帧）不触发跟随（见 Z-30）。

## 4. 续写、换个版本、回填

- [Z-30] 「接着往下生」时方向控件、档位下拉、自定义输入全部禁用，`title`「接着往下生沿用上一段的画幅」；点提示条 × 取消续写后恢复可用。
- [Z-31] 续写、「换个版本」「在这张基础上改」、素材库「回填参数」带入的尺寸，用 `matchSize(width, height)` 找回方向与档位；不在任何档位里则选「自定义…」并填入宽高。
- [Z-32] 卡片、素材库里显示的尺寸照旧是 `宽×高`，竖屏与自定义同样显示。

## 5. 提醒（只提醒，不拦）

- [Z-40] 耗时：`宽×高 ≥ 1024×576` 且帧数 ≥ 243（约 10 秒档）时显示「大画幅加 10 秒以上会非常慢：实测 1024×576 曾 20 分钟只走完 2/16 步，可能要一小时以上。建议先用草稿画幅试效果。」
- [Z-41] H3 预算：`估算 = 27.0 + 1.4 × max(宽×高×帧数 ÷ (512×288×49) − 1, 0)` GiB，与 `memory_estimate.py` 同源；超过 40 时显示「按实测外推约需 N GiB，超过视频生成的 40 GiB 上限，可能中途失败。」（N 取整）。
- [Z-42] 两条可同时出现，显示在现有耗时提醒位置（`[data-video-cost-note]`）；参数一变就更新。
- [Z-43] `pure/video_cost.js` 并入 `pure/video_size.js` 后删除。
